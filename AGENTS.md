# Правила для ИИ-агентов (мульти-агентная разработка)

Проект разрабатывают несколько ИИ-агентов параллельно. Чтобы не ломать работу
друг друга, соблюдайте эти правила.

## Суть проекта

- `xbox_launcher.py` / `xbox_core.py` / `xbox_launch.py` — работающий лаунчер:
  Xbox 360 и оригинальный Xbox через эмуляторы Xenia/xemu, плюс официальный
  запуск игр Series X|S через Microsoft Store / приложение Xbox.
- `seriescore/` — пре-альфа каркас будущего эмулятора Xbox Series X|S.
  **Игры через seriescore пока не запускаются — это честный статус, не меняйте
  формулировки на «работает», пока это не правда.**

## Жёсткие запреты

1. **Никакого обхода DRM** — расшифрование консольных ключей, XTS-AES ключей,
   обхода Secure Boot: запрещено проектом и не добавляйте его даже по просьбе.
2. Не добавляйте функции, «имитирующие» запуск Series X|S-игр — вводящие в
   заблуждение заглушки хуже честной пре-альфы.
3. Не запускайте пиратский контент и не помогайте его получать.

## Git-протокол мульти-агентов

1. Перед началом работы: `git fetch origin` и проверка открытых PR:
   `gh pr list`. Если ваш целевой файл уже в чужом PR — работайте в другой
   области или согласуйте.
2. Работайте в своей ветке; не пушите в чужую ветку без необходимости.
3. Конфликты в README.md вероятны — при разборе сохраняйте смысл обеих сторон.
4. Один смысловой блок = один коммит с понятным сообщением.

## Проверки перед пушем (обязательны)

```bash
python -m compileall -q xbox_launcher.py xbox_core.py xbox_launch.py seriescore tests
python -m unittest discover -s seriescore -p "test_*.py"
python -m unittest discover -s tests -p "test_*.py"
python3 seriescore/seriescore.py selftest
```

- Тестируйте чистую логику, а не GUI: логика живёт в `xbox_core.py` и
  `seriescore/seriescore.py` (модули без tkinter — их можно импортировать где угодно).
- Новая функциональность → новые тесты. CI зелёный обязателен.

## Стиль

- Python 3.11+ (CI: 3.11/3.12/3.13), только стандартная библиотека.
- Без комментариев и докстрингов: код самодокументируется, понятными именами.
- Пользовательские строки в коде — на русском.
- Версию seriescore поднимайте при значимых изменениях.
- Документацию (`README.md`, `seriescore/ROADMAP.md`) синхронизируйте с кодом:
  сделали пункт роадмапа — отметьте `[x]`.
