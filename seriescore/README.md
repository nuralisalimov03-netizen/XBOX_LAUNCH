# SeriesCore — каркас эмулятора Xbox Series X|S

> **Статус: пре-альфа 0.0.1. Игры НЕ запускаются.** Это фундамент и карта пути,
> а не законченный эмулятор. Создание эмуляции Xbox Series X|S — проект на годы.

## Что уже умеет CLI

```bash
python3 seriescore.py status        # состояние проекта и список модулей
python3 seriescore.py xvd-info F.xvd   # базовая информация об образе XVD
python3 seriescore.py selftest      # внутренняя проверка
```

Тесты: `python -m unittest discover -s seriescore -p "test_*.py" -v`
CI прогоняет компиляцию и тесты на Python 3.11 / 3.12 / 3.13.

## Честные вводные

- **CPU консоли — AMD Zen 2 (x86-64)**, тот же набор инструкций, что у ПК. Значит,
  динамическая трансляция инструкций почти не нужна: главная работа — точная
  эмуляция системного ПО и API (kernel, D3D12 Ultimate, сервисы Xbox).
- **GPU — AMD RDNA 2.** Современные видеокарты AMD тех же поколений говорят
  «на близком языке», поэтому реалистичный путь — перехват D3D12U-команд и их
  повторная подача через Vulkan/D3D12 хоста.
- **Загрузчик и хранилище зашифрованы (XTS-AES в XVD, Secure Boot, Pluton).**
  Проект не включает и не будет включать обход DRM. Симулятор работает только
  с контентом, к которому у вас есть легальные права (например, Xbox Play Anywhere
  в Microsoft Store — это «эмуляция Series X|S on PC» на уровне официальной технологии).

## Почему это не «неделя работы»

Xenia (Xbox 360) разрабатывается более 10 лет и всё ещё не идеальна.
Здесь поколение новее: там, где у 360 был PowerPC (нужна трансляция), у Series X|S
проблема наоборот — CPU уже совместим, зато система закрыта сильнее (Hyper-V,
шифрование, сервисы). Каждый модуль из `seriescore.py status` — месяцы работы.
