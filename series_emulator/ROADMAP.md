# SERIES EMULATOR — Roadmap для совместной работы агентов

Честная постановка: настоящий эмулятор Xbox Series X/S = эмуляция AMD Zen 2
(8 ядер), RDNA 2 (12 TFLOPS), 16 ГБ ОЗУ и проприетарной ОС на базе Windows.
Это годы работы. Этот каталог — **каркас проекта**, в котором уже работают
модули ядра, GPU-растеризатор, память и сампл-консоль, и его можно расширять
до полноценного эмулятора, постепенно заменяя заглушки реализациями.

## Текущее состояние (phase 0 — каркас)

| Модуль | Статус | Что уже работает |
|---|---|---|
| `memory.py` | работает | линейная little-endian память, чтение/запись u8/u16/u32/u64, регионы |
| `gpu.py` | работает | RDNA-окно framebuffer, clear + треугольная растеризация (barycentric) → PPM |
| `apu.py` | заглушка | буфер сэмплов PCM, микширование суммы каналов |
| `input.py` | работает | состояние геймпада (оси + кнопки), клиппинг осей |
| `kernel.py` | работает | таблица объектов, аллокатор ядра, системные вызовы, boot-лог |
| `console.py` | работает | сборка консоли, boot() → отчёт о запуске, run_frame() |
| `cli.py` | работает | `--selftest`, `--boot-ppm <out.ppm>`, `--status` |

## Как этим пользоваться агентам

1. Запуск: `python -m series_emulator --selftest` — должно напечатать `SERIES EMULATOR SELFTEST OK`.
2. Тесты: `python -m unittest tests.test_series_emulator -v`.
3. Главный вход — `series_emulator.console.SeriesConsole`. Создавайте консоль
   через `SeriesConsole.boot()`, рисуйте через `gpu.raster_triangle`, добавляйте
   новые модули рядом, не ломая API существующих.
4. Любые изменения ядра/GPU обязаны идти вместе с тестами в
   `tests/test_series_emulator.py`.

## Этапы до «настоящего» эмулятора

- **Фаза 1 — CPU.** Интерпретатор x86-64 (подмножество SSE), позже DynaRec
  в машинный код. Писать в `cpu.py` рядом с заглушкой `StubCPU`.
- **Фаза 2 — GPU.** Довести до RDNA-подобного шейдерного мини-ISA, потом
  перенести на Vulkan/Metal/DX12. Сейчас — чисто софтверный растеризатор в `gpu.py`.
- **Фаза 3 — ядро ОС.** HLE-эмуляция нужных системных вызовов модифицированной
  Windows (тут `kernel.py` как основа таблицы объектов и сисколов).
- **Фаза 4 — APU/audio, ввод, сеть.** Сейчас заглушки.
- **Фаза 5 — загрузка реального контента.** Реальные образы Xbox Серии X/S
  потребуют аппаратных дескрипторов/ключей, которых вне легального поля нет.
  Пока проект полностью умещается в модель «свой контент = свой payload».

## Ограничения, о которых надо помнить

- Никаких leaked-SDK, приватных дескрипторов и ключей не используем.
- Все имена файлов/модулей обязаны оставаться `_snake_case`.
- Лаунчер (`xbox_series_launcher.py`) и эмулятор — независимые подпроекты
  репозитория: лаунчер запускает реальные игры через Xenia/xemu, каркас
  эмулятора развивается параллельно и не должен его ломать.
